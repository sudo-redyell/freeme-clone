# URL → 마크다운 변환 후 LLM으로 바로 넘기기

웹 페이지 URL을 붙여넣으면 본문을 마크다운으로 추출해 보여주고, 그 결과를 복사·다운로드하거나 프롬프트와 함께 ChatGPT·Claude로 바로 넘길 수 있는 단일 화면 서비스.

## 사용자에게 보이는 결과

- 사용자는 URL을 입력하고 "변환하기"를 눌러 해당 페이지 본문이 마크다운으로 추출된 결과를 확인할 수 있다.
- 결과 화면에는 원본 페이지의 제목과 저자(확인 가능한 경우)가 헤더로 표시되고, 그 아래 렌더링된 마크다운 본문이 표시된다.
- 사용자는 변환된 마크다운을 클립보드에 복사하거나 `.md` 파일로 다운로드할 수 있다.
- 사용자는 변환 결과를 ChatGPT 또는 Claude로 넘길 수 있다. 이때 대상 사이트가 새 탭으로 열리고, 동시에 "프롬프트(선택) + 마크다운" 텍스트가 클립보드에 복사되어 입력창에 붙여넣기만 하면 된다.
- 사용자는 프롬프트로 프리셋(요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘) 중 하나를 선택하거나, "직접 입력"을 선택해 그 자리에서 원하는 문장을 입력할 수 있다. 프리셋 없이(프롬프트 없이) 넘기는 것도 가능하다.
- 사용자는 언제든 지우기 버튼으로 입력·결과를 초기화하고 새 URL을 입력할 수 있다.
- 사용자는 라이트/다크 모드를 토글로 전환할 수 있고, 이후 방문에도 선택이 유지된다.
- 변환에 실패하면(페이지 접근 불가, 본문 추출 실패 등) 오류 메시지가 표시되고, 입력했던 URL은 그대로 남아 있어 재입력 없이 다시 시도할 수 있다.

## 승인된 범위

- URL 입력 → 변환 → 결과 확인 → 내보내기(복사 / 다운로드 / ChatGPT·Claude로 열기)로 이어지는 단일 흐름.
- 본문 추출에는 defuddle 라이브러리를 사용한다(사용자 지정 필수 요건).
- 프롬프트 프리셋 3종 + 직접 입력 1종.
- 다크모드 토글.

## 관찰 가능한 수용 기준

- 유효한 공개 웹 페이지 URL을 입력하고 변환하면, 화면에 제목(있으면)·저자(있으면)·렌더링된 마크다운 본문이 나타난다.
- "복사하기"를 누르면 변환된 마크다운 본문(프롬프트 미포함)이 클립보드에 담긴다.
- ".md 다운로드"를 누르면 변환된 마크다운 본문(프롬프트 미포함)이 파일로 저장된다.
- "ChatGPT로 열기" 또는 "Claude로 열기"를 누르면: (1) 해당 서비스가 새 탭으로 열리고, (2) 선택된 프롬프트(있으면)가 앞에 붙은 마크다운 텍스트가 클립보드에 복사된다.
- 프리셋 옆 "직접 입력"을 선택하면 텍스트 입력창이 나타나고, 그 내용은 저장되지 않아 새로고침하거나 다른 URL로 넘어가면 사라진다.
- 접근할 수 없거나 본문 추출에 실패한 URL을 입력하면 오류 메시지가 표시되고, 입력창의 URL은 지워지지 않는다.
- 지우기를 누르면 URL 입력, 변환 결과, 선택된 프롬프트가 모두 초기 상태로 돌아간다.
- 다크모드를 켜고 새로고침해도 다크모드 상태가 유지된다.

## 결정 및 근거

- **본문 추출 라이브러리는 defuddle로 고정한다.** 사용자가 요구사항에서 명시한 필수 조건이다.
- **[[llm-handoff-mechanism]]: ChatGPT·Claude로 열기는 "새 탭 열기 + 클립보드 복사" 조합으로 구현하고, 벤더 미문서화 URL 프리필 파라미터에 의존하지 않는다.** 근거와 대안 비교는 `docs/decisions/llm-handoff-mechanism.md` 참고. 벤더가 공식 프리필 방식을 문서화하기 전까지는 재검토하지 않는다.

## 가정 (필요 시 뒤집을 수 있음)

- 변환은 URL을 붙여넣은 뒤 별도의 "변환하기" 동작으로 시작한다(붙여넣는 즉시 자동 시작하지 않는다).
- 복사하기 / `.md` 다운로드는 프롬프트를 포함하지 않고 변환된 마크다운 본문만을 대상으로 한다. 프롬프트 프리펜드는 "ChatGPT·Claude로 열기"에만 적용된다.
- `.md` 다운로드 파일명은 추출된 페이지 제목을 기반으로 하고, 제목을 확인할 수 없으면 기본 파일명을 사용한다.
- 변환 결과·입력값은 새로고침 시 초기화되며 서버에 저장되지 않는다(직접 입력 프롬프트의 "1회용" 방침과 동일선상).
- 제목·저자 등 메타데이터를 확인할 수 없는 페이지는 해당 항목을 생략하고 나머지(본문 등)만 표시한다.
- 화면의 UI 문구는 한국어로 제공한다.

## 범위 밖 (이유)

- **계정/로그인, 변환 이력 저장**: 요구되지 않았고 프롬프트 직접 입력의 "저장하지 않음" 방침과 상충한다.
- **요청 빈도 제한, 악성 URL 차단 등 보안 하드닝**: 이 프로젝트의 검증·리뷰 예산상 스펙이 요구하지 않는 보안 하드닝은 범위 밖으로 둔다.
- **로그인이 필요한 페이지, 자바스크립트 렌더링에 의존하는 SPA 페이지의 완전한 지원**: defuddle은 이미 확보된 HTML만 파싱하므로(브라우저 자동화가 포함되지 않는 한) 이런 페이지는 본문을 제대로 추출하지 못할 수 있다. 최선 노력(best-effort) 수준으로 두고, 완전한 지원은 이번 범위에 포함하지 않는다.

## 남은 위험

- 일부 사이트는 봇 차단, 로그인 요구, 또는 클라이언트 사이드 렌더링 의존으로 본문 추출이 실패하거나 품질이 낮을 수 있다(위 "범위 밖" 항목과 연결).
- "ChatGPT·Claude로 열기"는 클립보드 복사에 의존하므로, 사용자가 입력창에 직접 붙여넣는 한 단계가 항상 필요하다(완전 자동 전송이 아니다).
