# LLM handoff mechanism

## Decisions

- 변환 결과(및 선택된 프롬프트)를 ChatGPT·Claude로 넘길 때는 대상 사이트를 새 탭으로 열면서 동시에 "프롬프트 + 마크다운" 텍스트를 클립보드에 복사한다. 사용자가 입력창에 붙여넣기(Ctrl/Cmd+V)해서 완료한다.
- 벤더가 공식 문서화하지 않은 URL 프리필 파라미터(예: `?q=`)에 의존해 자동으로 입력창을 채우거나 자동 전송하는 방식은 사용하지 않는다.

## Boundaries

- 이 결정은 "ChatGPT·Claude로 열기" 기능에 한정된다. 복사하기 / .md 다운로드 기능은 이 결정과 무관하게 항상 클립보드·파일로만 동작한다.
- 향후 다른 LLM 서비스를 내보내기 대상으로 추가하더라도 동일한 방식(새 탭 + 클립보드 복사)을 기본으로 한다.

## Why

ChatGPT의 `?q=` 파라미터와 Claude의 동일 계열 파라미터는 각 벤더가 공식적으로 지원을 약속한 API가 아니라 관찰된 비공식 동작이다. 실사용 조사 결과 ChatGPT 쪽은 동작하지만 모델이 의도치 않게 강제로 바뀌는 버그가 보고되어 있고, Claude 쪽은 2025년 10월 무렵 제거된 사례가 확인되어 현재 안정적으로 동작한다고 보장할 수 없다. 또한 변환된 마크다운 전체를 URL 쿼리에 담아 전달하는 방식은 글이 길면 브라우저·서버의 URL 길이 제한에 걸려 잘리거나 요청이 실패할 위험이 있다. 이 프로젝트는 강의용 템플릿으로 "동작하는 결과물"이 우선이므로, 벤더 정책 변경이나 콘텐츠 길이에 관계없이 항상 동작하는 방식을 택했다.

## Reconsider when

- ChatGPT 또는 Claude가 입력창 프리필을 공식 API/딥링크로 문서화해 지원을 명시적으로 약속하는 경우.

## Still-rejected alternatives

- 비공식 프리필 파라미터로 자동 채움을 먼저 시도하고 실패 시 클립보드 복사로 폴백 — 성공 시 사용자 동작이 한 단계 줄어들어 더 매끄럽지만, 벤더가 예고 없이 동작을 바꾸면 조용히 깨질 수 있고 실패 감지·폴백 로직이 추가로 필요해 강의용 템플릿의 검증 예산을 넘어선다고 판단해 보류.
